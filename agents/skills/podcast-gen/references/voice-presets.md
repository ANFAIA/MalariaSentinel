# Voice Presets Reference

## How Voices Work

Kokoro-82M uses single-letter language codes and voice IDs in the format {gender}{lang}_{name}.

- Gender prefix: af_ = female, am_ = male
- Language code: a = en-us, b = en-gb, e = es
- Full voice ID: e.g. af_heart, am_adam, ef_dora
