# Papers traceability ledger

## Purpose

This ledger maps each Tier 1 numeric claim that code or a scoring target reads to the paper it is attributed to, so that the paper can be checked without the curated summaries (D17, D21). Citations name papers by DOI or manifest id, never by a Markdown file (D21, D22); `refuted` is set by the author only (D17).

Verdicts: `verified` = the value is quoted from the paper's abstract in the local summary; `unverified-paywalled` = not confirmed in this pass (includes open-access papers whose text was not read, and rows where the paper contradicts the claim; see Limitations). Rows marked **candidate** need the author's decision.

## Limitations

- **Verification route.** `web_search` returned no scientific literature for any DOI or title query in this pass, so no web confirmation was obtained. Verified rows rely only on abstract text quoted in the local summaries under `papers/`. Key-results tables in those summaries are not verbatim and were not used to verify.
- **Count.** 7 of 44 rows are verified (R01, R03, R05, R08, R10, R15, R20). 37 are `unverified-paywalled`. Most of the 37 are open-access papers whose full text was not read; the label means "not confirmed in this pass", not "behind a paywall". Sources absent from the corpus (Lardeux 2008, Kaufmann & Briegel 2004, Yang 2009, Tokarz & Novak 2018, Kelly 2012, Okumu 2013, Ward 2015, Giglioli) cannot be checked until fetched.
- **Refutation candidates for the author (D17).** R02, R06, R09, R11, R12, R21, R26, R37, R38. Each has a paper value that contradicts the claim as used. None is set `refuted` here. R41 is an internal conflict, not a paper conflict.
- **Not located.** Ward 2015 (registry D19), Giglioli (`egg_daily_mort` comment), and the D1 occupancy citations (Bogh 2004, Ndenga 2011 in `registry.py`) were not checked.
- **Outside the ledger.** `llm_verdict.md:76–79` gives adult density bands as "normalised 0.0–0.5", which predates state contract 4.0 (raw counts, K_MAX retired). `docs/papers-syntheses/dispersal-kernel-calibration.md` gives ADULT_DAILY_MORT_BASAL 0.93, which conflicts with the canon 0.87; the summary is stale.
