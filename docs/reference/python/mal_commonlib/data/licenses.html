mal_commonlib.data.licenses

Dataset license registry + restriction warnings (upstream licensing audit).

Every loader module (mal_commonlib.data.loaders.*) declares license (an identifier in KNOWN_LICENSES) and attribution (the literal credit line to reproduce in publications/maps) in its DOWNLOADER dict. The download runner stamps both into the manifest entry; ingest registers derived products with a +-joined compound license id derived from its inputs. Scr: docs/licenses.md — the human-readable audit + decision log (e.g. MERIT DEM: ODbL branch elected 2026-09-27).

Pipeline stages that produce or consume datasets call warn_limits() once per process; it aggregates which usage restrictions apply.

110def collect_limits(license_ids: Iterable[str]) -> list[str]:
111    """Aggregate usage-limit sentences for a set of license ids.
112
113    Compound derived ids are '+'-joined (e.g. ``CC-BY-4.0+ODbL-1.0``); in
114    that case every component id is kept only if it adds a restriction.
115    """
116    seen: dict[str, str] = {}
117    for raw in license_ids:
118        if not raw:
119            continue
120        for lid in raw.split("+"):
121            lid = lid.strip()
122            spec = KNOWN_LICENSES.get(lid)
123            if spec is None:
124                seen.setdefault(
125                    lid, f"Unknown license id {lid!r} — check docs/licenses.md"
126                )
127            elif spec.get("limit"):
128                seen.setdefault(lid, spec["limit"])
129    return list(seen.values())

132def warn_limits(license_ids: Iterable[str], *, stacklevel: int = 2) -> None:
133    """Emit a single aggregated UserWarning listing all usage limits."""
134    limits = collect_limits(license_ids)
135    if not limits:
136        return
137    body = "\n  - ".join(limits)
138    warnings.warn(
139        f"Upstream dataset licenses limit some uses:\n  - {body}\n"
140        f"  Full audit: docs/licenses.md",
141        UserWarning,
142        stacklevel=stacklevel,
143    )

146def warn_manifest_limits(aoi: str, data_root=None) -> None:
147    """Read an AOI manifest and warn once about its aggregate limits.
148
149    Called by download / ingest stages after registration.
150    """
151    from mal_core.download.manifest import read_manifest
152
153    manifest = read_manifest(aoi, data_root)
154    ids = [
155        (ds.get("license") or "")
156        for ds in manifest.get("datasets", {}).values()
157    ]
158    warn_limits([i for i in ids if i], stacklevel=3)
