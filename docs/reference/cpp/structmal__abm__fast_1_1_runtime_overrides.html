Detailed Description

Constants — match mal_ghana_sim.abm defaults exactly (M1.5 thin slice).

K_MAX retired (plan 03-retirada-k-max): the larval capacity is the absolute per-cell K_ref × area_km2 × S computed by the coordinator (habitat_availability.hpp k_habitat); initial populations are explicit adult/immature counts (SeedingConfig), and the state COG carries raw per-cell adult counts. No global adult-capacity constant exists anymore. EIP (extrinsic incubation period) growing-degree-day model. daily_gd = max(0, T - EIP_BASE_C) infective when eip_progress >= EIP_THRESHOLD_GD Adult dispersal kernel: isotropic Gaussian in metres, clipped at dispersal.adult_max_m (probabilities and widths come from dispersal.*). Windborne long-range migration (M7.6 Phase 1). Parameters come from dispersal.wind_* in model_constants.yaml. Egg batch size is temperature-scaled at oviposition time via the EFD thermal modifier (birth_rate.hpp): the binomial draw of GonotrophicParams::egg_batch_n trials uses p = (egg_batch_mean / egg_batch_n) × birth_rate_modifier(T), with T the same per-patch temp_d that drives adult survival. Larva density-dependent mortality (Beverton-Holt): the daily survival probability of the patch's larvae is p = S0 * K / (K + alpha * N), with S0 and alpha read from model_constants.yaml (aquatic_stages.larva_bh_s0 / larva_bh_alpha) and N the summed larval instars of the patch. Runtime-configurable overrides for dispersal and larval parameters. Used by CLI to override wire.hpp defaults for invasion simulations.
