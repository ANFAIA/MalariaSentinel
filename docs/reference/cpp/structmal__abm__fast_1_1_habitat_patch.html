Detailed Description

A single habitat patch loaded from the gpkg. Carries the cell (row, col), the static potential amplitude (H total in [0, 1]) and the dominant habitat type's dynamics label. proxy_habitat_v1 contract (env.py):

  • patch_id — row-major WM index for the (row, col); runtime assigned
  • potential — H_total = sum_g H[i,g] (attraction amplitude)
  • hab_col_ — the six per-type H features are carried at the coordinator level (habitat_features struct), not here.
