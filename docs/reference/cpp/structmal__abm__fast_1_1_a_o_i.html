Detailed Description

Value types — shared across all modules.

Area of Interest. Mirrors mal_commonlib.aoi.AOI (M1.2a) but in C++: the bbox (W, S, E, N) in EPSG:4326 degrees, the CRS string, the slug (used in file naming), the ground resolution in metres, and the scale level (matches the Python Scale enum: "regional" / "national" / "continental").

cells_per_side() returns the number of cells along the east-west axis (the WIDTH of the AOI in cells). The height can be derived symmetrically: H = round((north - south) * geodesy met/deg / resolution_m). The full inline implementation lives in aoi.hpp; the declaration is here so wire.hpp remains self-contained for the data types.
