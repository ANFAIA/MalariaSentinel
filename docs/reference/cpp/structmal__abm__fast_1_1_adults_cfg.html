◆ daily_mort_basal

double mal_abm_fast::AdultsCfg::daily_mort_basal = 0.0

Basal daily survival probability of an adult female, used as the constant factor of the thermal Gaussian and as the survival when no temperature is available. The name is historical: the value is a survival probability per day, not a mortality rate (adults.daily_mort_basal).
