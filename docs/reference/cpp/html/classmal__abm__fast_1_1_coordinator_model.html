◆ update_habitat_day()

void mal_abm_fast::CoordinatorModel::update_habitat_day ( float gamma_t = 0.0f)

Per-day: advance z with today's rainfall per cell, recompute the species-neutral daily accuracy S[i, t] and capacity K[i, t], and track per-cell dry-day streaks. Call AFTER climate_->set_day(). gamma_t: temperature scaling of the pluvial drying memory — tau_eff = pluvial.dry_memory_days * (1 - gamma_T * clamp((T_opt - temp)/T_ref)) when gamma_T > 0.

◆ warm_up_pluvial()

void mal_abm_fast::CoordinatorModel::warm_up_pluvial ( int32_t n_warmup_bands)

Integrate the pluvial state z causally over every env-NC band from base_day - n_warmup_bands to base_day - 1, starting from z = 0 at the cold end. Called once by the Engine facade before the daily loop (plan §6.5 warm-up Causal).
