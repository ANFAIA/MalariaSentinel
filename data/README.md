# Data

Datasets used across the MalariaSentinel research.

## ⚠️ Gitignored — download on demand

Raw occurrence files (`.txt`), DwC-A archives (`.zip`), SRTM rasters, and the
AOI env/host rasters are **kept out of git** to avoid bloating the repo.
Folder structure and small metadata files are tracked.

Two data layers live here:

1. **AOI pipeline data** (`data/<aoi>/`) — everything the ABM pipeline needs,
   downloaded and registered by `malariasim download`. The AOI manifest
   (`data/<aoi>/manifest.json`) is the **single source of truth** for the
   inventory; never hardcode paths, resolve from the manifest
   (spec: `docs/specs/data/spec.md`).

   ```bash
   uv run malariasim download --aoi ghana --datasets era5 --outputs wind_6hourly --years 2024,2025
   uv run malariasim ingest --aoi ghana --year 2024 --month 6
   # Validate completeness:
   uv run python -c "from mal_core.download.manifest import validate_completeness; print(validate_completeness('ghana'))"
   ```

2. **Reference occurrence datasets** (`ghana_idit/`, `react/`, `guf/`,
   `colombia_vl/`) — GBIF IPT DwC-A archives used by `mal-data-explorer` for
   mapping and bias analysis. Re-download from the IPT sources listed in the
   table below (no auth).

## Structure

```
data/
  ghana/                Ghana AOI — pipeline data (manifest.json + env/host/mobility files)
  ghana_idit/           Ghana IDIT — Anopheles phenotypic (larval sampling)
  colombia_vl/          Colombia — Timbiquí/Guapi/Santa Bárbara (PMI VectorLink)
  react/                REACT IRD — Burkina Faso + Côte d'Ivoire
  guf/                  Institut Pasteur Guyane — French Guiana
  colombia/             Legacy dir from an earlier failed download (not restored)
  maps/                 Output PNG figures (tracked, regenerated by explorer)
  runs/                 Explorer/scratch outputs (gitignored)
  moua_2016.pdf         Moua et al. 2016 — tracked (open-access paper)
  pasteur_anopheles.zip Gitignored (raw DwC-A archive copy for GUF)
  README.md             This file
```

## Notes

- The IPT archives occasionally change (columns get added/dropped). The GUF
  archive currently ships many DwC columns as NaN (sex, month, day, habitat,
  eventRemarks, waterBody, country, coordinatePrecision, typeStatus) — this is
  a difference in the upstream archive, not a download bug. The
  `mal-data-explorer` scripts are defensive against empty fields.
- `data/colombia/colombia.zip` (a broken HTML file from an earlier failed
  attempt at a different Colombia dataset) is intentionally NOT re-downloaded.
